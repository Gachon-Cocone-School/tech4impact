## 강의 개요

“Tech for Impact”는 기술을 통해 사회 문제를 해결하는 방법을 배우고, 직접 혁신적인 솔루션을 기획·개발하는 실전 프로젝트 중심 수업입니다.

이 강의는 카카오임팩트 재단의 “Tech for Impact 캠퍼스” 사업의 일환으로 KAIST, 서울대, 연세대, 한양대 등 국내 19개 대학들과 함께 공동으로 운영됩니다.

학생들은 사회 혁신가(브라이언임팩트 재단의 펠로우)들의 실제 경험담과 사례를 듣고, 이들이 제시한 탐색 공간에서 문제를 발굴하고 기술을 통해 더 확장될 수 있도록 팀별로 새로운 솔루션을 기획·제안하게 됩니다.

8월 29일(토) 온라인 개강 워크숍으로 수업이 시작됩니다. 워크숍에서는 사회 혁신가, 카카오 개발자, 참여 대학 학생들이 함께 오리엔테이션 및 교류의 시간을 가집니다.

수업 중에는 환경, 다양성, 건강, 정치 등 여러 분야에서 활동하는 사회 혁신가들과 교류하며 문제 정의, 가설 검증, 사용자 인터뷰, 솔루션 기획, 프로토타입 제작을 카카오 현업 개발자의 멘토링과 함께 경험하게 됩니다. 그리고 이러한 프로젝트 진행 과정과 주제 발표, 중간 발표, 최종 발표를 포함한 전 과정이 팀 단위로 진행됩니다.

사용자 인터뷰, 실습 도구 구입 등 필요한 **활동비가 지원**되며, 카카오 개발자들의 기술 멘토링과 피드백, 브라이언임팩트 펠로우의 현장 경험이 더해집니다.

모든 과정을 수료하면 공식 수료증이 발급되고, 우수 프로젝트 및 학생에게는 상금 및 후속 프로젝트 지원이 제공됩니다.

이 강의는 기존 이론 중심 강의와 달리, 실전 문제 해결 경험, 현업 사회혁신가와의 네트워킹, 국내 주요 대학 및 기업과의 협업 경험을 한 번에 쌓을 수 있는 특별한 기회를 제공합니다.

## 성적 산출

성적은 아래의 비중에 따라 계산됩니다.

### 수업 참여도(출석 및 과제) 평가(50점)

수업 참여도는 **감점제**로 평가합니다.

#### 출석 규칙

* 결석 1회당 9점을 감점합니다. 단, 공결은 감점하지 않습니다.
* 지각 1회당 3점을 감점합니다. 단, **지각 1회까지는 감점하지 않습니다.**

  * 수업 시작 10분 후 수업에 참여하는 경우 지각으로 간주합니다.
  * 수업 시작 1시간 이후에 도착하는 경우 결석으로 간주합니다.
* 결석 3회부터는 나머지 성적에 관계없이 A학점을 받을 수 없습니다.
* 결석 4회는 학칙에 의해 학점 부여가 불가능하며 F학점이 부여됩니다.

#### 과제 규칙

* 주간보고서 제출이 지정된 수업의 경우 출석 확인을 대신하여 **주간보고서를 개인별로 제출**해야 합니다.
* 주간보고서는 **가천대학교 이메일을 이용하여 메일 본문에 직접 작성하여 제출**해야 합니다.
* 감점은 누적되며, 각 보고서마다 최대 9점의 감점이 적용될 수 있습니다.
* 미제출 시 9점을 감점합니다.
* 제출시간보다 늦게 제출한 경우 **12시간마다 1점씩 감점**합니다.

  * 따라서 4.5일 이상 늦게 제출할 경우 미제출과 동일하게 9점이 감점됩니다.
* 보고서 내용이 부실한 경우 3점을 감점합니다.
* 가천대학교 이메일이 아닌 다른 이메일 계정으로 제출하는 경우 2점을 감점합니다.
* 메일 본문이 아닌 첨부파일로 작성하여 제출하는 경우 2점을 감점합니다.
* 개별 과제에 별도의 과제 규칙이 제공되는 경우 해당 규칙을 우선 적용합니다.

### 프로젝트 산출물 평가(50점)

프로젝트 산출물 평가는 **가점제**로 평가합니다.

프로젝트 기간 동안 총 3회의 발표회가 진행되며, 각각 다음과 같이 배점합니다.

* 팀별 주제 발표 : **10점**
* 중간 성과 발표 : **15점**
* 최종 성과 발표 : **25점**

발표 평가는 학생 및 참여자 투표 평가와 교수진의 평가를 함께 반영합니다.

또한 프로젝트 기간 동안 팀원 간 협업의 중요성을 체감할 수 있도록 각 발표회 직후 **개인별 팀내 기여도 평가**를 실시합니다.

각 발표회의 개인별 점수는 **팀별 순위 점수 50점 + 팀내 기여도 점수 50점**을 합산한 뒤, 해당 발표회의 배점에 맞게 환산합니다.

#### 팀별 순위 점수

각 발표회별로 학생들의 투표와 교수진 평가를 합산하여 팀별 순위를 산출합니다.

* 1위 : 50점
* 2위 : 40점
* 3~4위 : 30점
* 5~6위 : 20점
* 그 외 : 10점

#### 팀내 기여도 점수

발표회 직후 팀원 전원이 설문에 참여하며, **팀원 N명에게 합계 100점을 배분**합니다.

개인이 팀원들로부터 받은 평균 기여도 점수를 팀 인원수에 따른 **정규화 기준점**과 비교하여 50점 만점으로 환산합니다.

> 정규화 기준점 = 100 ÷ 팀원 수(N)
> 예) 3인 팀 : 33.3점 / 4인 팀 : 25.0점

| 정규화 기준점 대비 개인 기여도 | 기여도 점수 |
| :---------------- | -----: |
| 140% 이상           |    50점 |
| 120% 이상 ~ 140% 미만 |    45점 |
| 100% 이상 ~ 120% 미만 |    40점 |
| 80% 이상 ~ 100% 미만  |    30점 |
| 60% 이상 ~ 80% 미만   |    20점 |
| 60% 미만            |    10점 |

#### 주제 발표회 평가 - 10점 만점

`(팀별 순위 점수 + 팀내 기여도 점수) × 0.1`

#### 중간 성과 발표회 평가 - 15점 만점

`(팀별 순위 점수 + 팀내 기여도 점수) × 0.15`

#### 최종 성과 발표회 평가 - 25점 만점

`(팀별 순위 점수 + 팀내 기여도 점수) × 0.25`

## 이번 학기 주제 목록

이번 학기 프로젝트는 사회혁신가가 이미 정의한 문제를 그대로 해결하는 방식이 아닙니다.  각 펠로우가 활동하고 있는 현장과 문제의식을 하나의 **탐색 공간(Problem Space)**으로 삼아, 학생들이 직접 현장을 조사하고 사용자를 만나 해결할 가치가 있는 문제를 발굴합니다.  학생들은 팀별로 문제를 정의하고 가설을 세운 뒤 사용자 인터뷰와 실험을 통해 이를 검증합니다. 이후 AI, 데이터, 소프트웨어 등 기술을 활용하여 해결 방법을 설계하고 실제 작동하는 프로토타입으로 발전시킵니다.
